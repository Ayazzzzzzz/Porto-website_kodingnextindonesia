# Porto-website_kodingnextindonesia# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built as part of the **Advanced Teacher Preliminary Evaluation at Koding Next**. This project demonstrates core web development skills using **HTML5, CSS3, Bootstrap 5, and JavaScript**, designed with a clean, beginner-friendly structure suitable for teaching students.

---

## 📌 Features & Teaching Highlights
- **Responsive Design:** Built using the Bootstrap 5 grid system for seamless viewing across devices.
- **Hybrid Content Delivery:**
  - *Static HTML:* Header, Navbar, About Me, and Contact sections (ideal for teaching basic HTML tags and structure).
  - *Dynamic JavaScript Rendering:* Project items are stored in a JavaScript array of objects (`script.js`) and dynamically rendered into the DOM using loops, teaching efficiency and data-driven web design.
- **Modern UI:** Clean, minimalist layout without cluttered boxes or unnecessary cards.

## 🚀 How to Run Locally

1. Clone or download this repository to your local machine.
2. Open the folder in **VS Code**.
3. Install the **Live Server** extension in VS Code.
4. Right-click on `index.html` and select **"Open with Live Server"**.

---

## 🌐 Deployment (GitHub Pages)

To make this portfolio accessible online via a public URL:
1. Create a new public repository on GitHub.
2. Push all project files to the `main` branch.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, select the `main` branch and `/root`, then click **Save**.
5. Your live URL will be generated within a minute!
